# Frame — 動画編集アプリ

ブラウザで動画を読み込み、カット・音量調整・複数動画の結合・字幕／テキスト追加・BGMや別音声の追加を行い、MP4 に書き出すアプリです。

## Windows でダウンロードして使う

1. [GitHub のリポジトリ](https://github.com/haruharu625/1) を開き、緑の **Code → Download ZIP** を選びます。非公開リポジトリの場合は、アクセス権のある GitHub アカウントでログインしてください。
2. 保存した ZIP を右クリックして **「すべて展開」**。展開したフォルダー（`1-main` など）を開きます。
3. **`SETUP-WINDOWS.cmd`** をダブルクリックし、初回のインストール確認で **Y** を押します。
4. 完了後、**`START-FRAME.cmd`** をダブルクリックすると、ブラウザで FRAME が開きます。

`index.html` 単体を直接開く方法では動きません。編集中は起動用の黒いウィンドウを開いたままにしてください。詳細は [Windows の手順](WINDOWS.md) を参照してください。

Windows 実機での動作は未検証です。起動ツールと動画編集・書き出しは Linux 上で検証しています。

## 開発用の起動

Node.js 20 以降と `ffmpeg`・`ffprobe` が必要です。日本語字幕には Noto Sans CJK フォントを使用します。追加の npm パッケージは不要です。

```sh
cd /workspace/1
npm start
```

標準ポートは `3000` です。`HOST` と `PORT` 環境変数で変更できます。

## 使い方

1. 動画を読み込みます。複数ファイルも追加できます。
2. クリップを選び、開始・終了時刻と音量を調整します。
3. クリップを並べ替え、必要に応じて字幕の内容と表示時刻を設定します。
4. 必要なら左の「音声」から BGM や別の音声ファイルを追加します。音声を選び、使う範囲・動画内で流し始める位置・音量を調整できます。
5. プレビューを確認し、MP4 を書き出してダウンロードします。

プレビューは動画の縦横比を保ち、画面内に動画全体が収まるよう自動調整します。

書き出し時は先頭クリップのサイズを基準に映像を揃え、縦横比を保って余白を追加します。音声のない動画も結合できます。字幕の時刻は、結合した動画全体の開始からの秒数です。

素材は 1 ファイル 500 MB・4 時間以内、最大 30 個です。1 回の編集ではクリップ 20 個、字幕 20 個（各 200 文字）まで使用できます。出力は最大辺 1920 px・30 fps の H.264／AAC MP4 です。

音声素材は MP3・WAV・M4A・AAC・OGG・FLAC・WebM に対応し、1 ファイル100MB、最大20個まで読み込めます。動画全体に対して最大8本の音声を重ねられます。音声は既定で50%の音量です。追加した音声は元動画の音に重なるため、置き換えたい場合は動画クリップの「オーディオ」をミュートしてください。音声の「開始」「終了」は素材内の範囲、「動画内で流し始める位置」は結合した動画全体の時刻です。動画末尾を超えた部分は書き出し時にカットされます。ブラウザが対応しない音声形式はプレビューできない場合がありますが、書き出しには利用できます。

動画は処理のためアプリサーバーの一時領域へアップロードされます。クラウドストレージへの保存機能はありません。サーバーの再起動後は再読み込みが必要です。認証を備えていない開発用アプリのため、公開環境で使用する際はアクセス制御を用意してください。

## 検証

```sh
npm test
```

短いテスト動画・音声を生成し、読み込み、部分配信、サムネイル、カット、結合、ミュート、短い音声の無音補完、日本語字幕、BGMの開始位置・音量・混合と MP4 出力を確認します。生成物は一時ディレクトリへ置き、終了時に削除します。

Python の Playwright と Chromium が利用できる環境では、ファイル選択のブラウザ回帰テストも実行できます。

```sh
python3 tests/file_picker_test.py
python3 tests/preview_test.py
python3 tests/audio_browser_test.py
```

一時サーバーを自動起動し、4 か所の追加欄の実クリック、キーボード・タッチでの選択、動画の読み込み、保存 HTML・スクリプト読み込み失敗時の案内と `crypto.randomUUID` が使えない場合の動作を確認します。Chromium の標準パスは `/usr/bin/chromium` です。異なる場合は `CHROMIUM_PATH` を指定できます。
プレビューの検証では縦・横・正方形動画の四隅の実画素、縦横比、リサイズ後の安定性を確認します。音声のブラウザ検証では実ファイル選択からカット・配置・音量・同期再生・MP4ダウンロードまでを確認します。
管理ブラウザのポリシーが `file://` を禁止する場合、保存 HTML を直接開く検証だけをスキップします。

書き出しはサーバーの CPU と一時ディスクを使用します。長い動画や高解像度の動画は処理に時間がかかります。同時書き出しは 2 件までで、使用されない素材と結果は約 6 時間で削除されます。
